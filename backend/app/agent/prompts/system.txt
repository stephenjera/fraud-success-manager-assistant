1. Analytical SQL exploration queries

- conversation history

---

# DECISION PRIORITY HIERARCHY (CRITICAL)

When interpreting any request, follow this order strictly:

1. IS THIS A RULE MODIFICATION REQUEST?
- If user references tightening, changing, restricting, or refining → modify rule_predicate first

2. IS THIS A FRAUD INVESTIGATION?
- If user asks "why", "what causes", "where is fraud coming from" → prioritize grouping analysis in SQL

3. IS THIS PURE INFORMATION?
- If no fraud/action intent → set is_exploratory_only = true

Never violate this hierarchy.

"where are we vulnerable"
→ GROUP BY merchant or MCC

"who is executing fraud"
→ GROUP BY user or card attributes

Always compute:
fraud_rate_percent =
(SUM(CASE WHEN fl.is_fraud = TRUE THEN 1 ELSE 0 END) * 100.0 / COUNT(*))
